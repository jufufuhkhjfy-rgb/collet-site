Collet

楽天ROOMの投稿準備を、
ワンボタンで。

Collet は、楽天市場のランキングから人気商品を探して、紹介文と紹介カード画像を用意する Windows 用のツールです。投稿を確定する「完了」は、毎回あなたが押します。

料金を見る 無料でダウンロード

基本の機能は無料です。有料プランは月300円から。いつでも解約できます。

できること

人気商品を自動で探す

インテリア・雑貨・ファッション・PCガジェットなど、選んだジャンルのランキングから、レビューの良い商品を集めます。

紹介文を用意する

PCで動くAIかテンプレートで、商品ごとの紹介文を作ります。投稿前に読んで、自由に書き直せます。

紹介カード画像

商品・レビューと価格・おすすめポイントの3枚の画像を作ります。背景がAI画像であることは、紹介文に自動で書き添えます。

ROOMの投稿画面に入れる

Chrome 拡張機能が、ROOMの投稿画面に紹介文と画像を入れます。あとは確認して「完了」を押すだけです。

はじめ方

  1. ダウンロードして展開

    「無料でダウンロード」を押すと、Collet.zip がダウンロードされます。右クリック →「すべて展開」で、好きな場所に置きます。

  2. setup.bat をダブルクリック

    Python などの必要な部品が自動で入り、デスクトップに Collet のアイコンができます。「PC が保護されました」と出たら、「詳細情報」→「実行」を押します。

  3. 楽天のアプリIDを入れる

    楽天ウェブサービスで、無料で取れます。取り方は、Collet の説明書に書いてあります。

  4. Chrome 拡張機能を入れる

    フォルダの中の extension を Chrome に読み込みます。これで、ROOMの投稿画面に紹介文と画像が入るようになります。

有料プランは、申し込んだあとに表示される利用キーを、Collet の「設定」に貼って保存するだけです。くわしい手順は Collet の説明書 にあります。
